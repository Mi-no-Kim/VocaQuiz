# VocaQuiz

보카로 곡의 한 구간을 듣거나 한 장면을 보고 곡을 맞히는 웹 퀴즈. Spring Boot + React, 1인 개발.

**설계의 제1원칙: 퀴즈 유형은 계속 추가된다.**
새 유형 추가 = 백엔드 클래스 1개 + 프론트 컴포넌트 1개. DB 마이그레이션 0, 기존 코드 수정 0.

## 잊으면 안 되는 것

- **`search.list`를 호출하지 않는다** — 호출당 100 units, 하루 100번이 끝 (D-034)
- **구간이 없는 곡은 출제되지 않는다** — 구간 찍기는 사람이 한다 (D-017)
- **정답은 라운드 종료 전까지 클라이언트로 나가지 않는다**
- **라운드 점수는 항상 0..100** (D-023)
